# DSA-4-UNIT-CCE
Objective

To develop an Employee Record Management System using a Binary Search Tree (BST) in C++.

Problem Statement

Create a system to insert and delete employee records and display the height, leaf nodes, internal nodes, and nodes with exactly one child in a BST.

Features

Insert employee ID.

Delete employee ID.

Display employee IDs in sorted order.

Calculate tree height.

Count leaf nodes.

Count internal nodes.

Count nodes with exactly one child.

Algorithm

Start the program.

Create an empty Binary Search Tree.

Insert employee IDs according to BST rules.

Delete an employee ID when required.

Display employee IDs using inorder traversal.

Calculate the height, leaf nodes, internal nodes, and nodes with one child.

Repeat until the user selects Exit.

Stop the program.
